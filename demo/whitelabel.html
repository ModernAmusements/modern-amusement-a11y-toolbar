White-Label Default Accessibility Toolbar

White-label default

A neutral starting point for client sites: Alliance No.1, black on white, 1px hard lines, square corners. No branding, no dependencies.

The accessibility toolbar inherits this theme through whitelabel.css — same palette, same type, same line weight.
